Connect your installation

In Clinical Notebook, open Settings → Connected Apps. Create a named Study Hub connection with notebook-list and source-import permissions, choose the allowed notebooks, then copy its API base URL and integration token here.

A loopback URL works only when the Hub and Clinical Notebook run on the same computer. For another computer, use its explicitly configured HTTPS integration gateway. Keep Clinical Notebook running; this connection does not open the app.

Checking connection…

The token is encrypted on the Hub and is never returned to this page. To revoke the connection entirely, revoke it in Clinical Notebook Connected Apps.
