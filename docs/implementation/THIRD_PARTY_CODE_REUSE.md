## Gemini SDK dependency rejection analysis

The standard library and current dependencies provide HTTP, validation, and retry primitives,
but not the official typed Gemini File Search stores, files, operations, interactions, or API
compatibility surface required by Tasks 2.2–2.8. Hand-rolling those contracts would duplicate the
approved maintained SDK. The deprecated `google-generativeai` package is explicitly rejected.
