## Sol-2 consuming review amendment

Sol-2 returned **BLOCK** on the initial CP-0002 proposal with three required
corrections. The amended proposal now:

1. freezes bounded slug-safe scope IDs with 96-bit full-input digests and a
   composed `StoreKey.course` parse round-trip gate;
2. requires Task 1.7's read-only `resolve_index_input(source_revision_id)` view
   to own all legacy resolution and expose verified canonical artifacts,
   hashes, state, authority, scope, evidence, and assets to Sol-2; and
3. requires one atomic Source Trust activation that marks prior ready slide
   revisions stale before the replacement becomes ready/indexable.

Sol-2's residual verdict found that scope-only supersession could stale a
transcript, handout, objective set, or other independent source in the same
lecture. CP-0002 now keys supersession by
`(source_family, authority_class, course_id, exam_id, lecture_id)`, fixes this
adapter's family as `legacy_slides`, and derives membership from the existing
adapter-owned source-document namespace without adding a column. Acceptance
tests 12-13 now require family isolation and a real race across independent
SQLite connections.

The amendment preserves the compatibility `sr_` identity,
`course_material` authority, and `source_sha256` file-hash meaning. Its exact
evaluation is that no Sol-0-owned shared JSON/provider schema, central database
migration, or wiring change is required if Sol-0 and Sol-2 approve CP-0002.
Failure to prove unique ready-per-source-family/scope activation with existing
columns is the explicit stop that would require a Sol-0-owned additive schema
change.
