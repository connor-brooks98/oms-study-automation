## Sol-0 adapter proposal

Runtime capture is deliberately deferred. Program Sol-0 should add one shared adapter/wiring change after the current quiz and Ask contracts are ready:

1. `src/oms_hub/web/public_quiz_routes.py` — inject `MasteryRepository` from `request.app.state`, preserve the existing `grade_answer(...)` call and response body, and append only after grading succeeds. Extend the browser request compatibly with optional `client_event_id`, `confidence`, `assistance_level`, `response_duration_ms`, and `attempt_timestamp`; existing clients omit these and receive the unchanged grading response. Map `question_id` to `question_version_id` (or the versioned question lookup once Task 5 publishes it), the published question's objective ID(s) to `objective_ids`, `choice_id` to `selected_option`, `feedback.correct` to `correct`, question difficulty when available otherwise `None`, client duration/timestamp to their corresponding fields, explicit assistance to `assistance_level` otherwise `none`, and the immutable published source revision hash to `source_snapshot_hash`. Use a browser-generated idempotency key as `client_event_id`; a retry of the same submission must return the existing event while grading remains unchanged. Event persistence failure must not replace the current grading result with a new error response; surface only a safe diagnostic through the established application logging/health path.
2. `src/oms_hub/ask/service.py` / `src/oms_hub/ask/routes.py` (the Task 3 owner’s files) — append `ask_question_submitted` after Ask request validation and `ask_answer_completed` only after a grounded answer reaches its terminal `done` result. Map `AskPageContext.objective_ids` and `QuizPageContext.question_id` when present; leave `correct`, `selected_option`, and `difficulty` null; map the request/message ID to `client_event_id`, server/client duration and terminal timestamp to the timing fields, and the retrieval packet's `source_snapshot_hash` to the source hash. Use `none` unless the user explicitly selected a hint, source excerpt, explanation, or answer reveal; a post-submit free-text Ask is not an automatic penalty. Do not append a completion event for validation rejection, insufficient-evidence short-circuit, cancellation, or failed generation.
3. `src/oms_hub/app.py` and the central migration/bootstrap owned by Sol-0 — import the mastery model before schema creation, construct `MasteryRepository` in app state, and register the isolated table through the normal migration path before enabling capture. This task intentionally does not edit those shared files.

Required Sol-0 tests: preserve the existing quiz feedback JSON and grading assertions while asserting the exact mapped `LearnerEvent`; retry the same browser `client_event_id` and assert one persisted event; exercise Ask validation/provider failure boundaries and assert only the permitted submitted/completed events; and run the existing quiz/Ask route suites with capture disabled to prove compatibility.
