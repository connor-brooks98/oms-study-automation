## Behavior guaranteed

- Input hashes use canonical JSON and sorted, duplicate-free source/evidence
  identifiers, so dependency ordering does not change the digest.
- Run and evidence-link values validate nonblank IDs, canonical SHA-256 values,
  UTC timestamps, READY/unretired dependency lifecycle, and evidence-to-source
  consistency before any write. SQLite triggers reject mismatched evidence
  pairs, and reads independently fail closed on corrupted persisted pairs.
- Exact retries return the stored run; reuse of an artifact ID with different
  immutable provenance fails without replacing the stored record. SQLite
  writes acquire one serialized transaction before lifecycle validation, and
  any observed unique race reloads and fully compares the committed winner.
- Staling a real Source Trust revision marks every dependent artifact with a
  durable reason, returns deterministic artifact IDs, remains idempotent, and
  deletes neither artifacts nor provenance links.
- Legacy outline and lecture-quiz backfill uses the accepted stable recipes,
  while generator-backed Studio publications use `custom-quiz-current` with
  token-plus-version identities and their persisted version/update timestamp;
  all preserve deterministic recoverable hashes, are restart-idempotent,
  retain superseded versions, record `legacy_unverified`, avoid double-counting
  lecture publications, and fabricate no source or evidence relationship.
- Artifact input hashing recursively admits only JSON data with string object
  keys, preventing integer/string, null/string, and boolean/string key
  collisions before canonical encoding.
