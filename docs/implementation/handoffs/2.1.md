## Produced interfaces

- `oms_hub.providers.gemini.GeminiProviderError`

- `oms_hub.providers.gemini.GeminiTransientError`
- `oms_hub.providers.gemini.GeminiContractError`

`GeminiConfig` is a provider-local Pydantic model. Its API key is a `SecretStr`, excluded from normal Pydantic serialization and `repr`; `to_redacted_dict()` returns JSON-safe settings plus only an `api_key_configured` boolean. Blank and whitespace-only keys are rejected. Positive timeout/size validation is enforced, the document limit cannot exceed 100 MiB, and the internal store-input limit cannot exceed 6,442,450,944 bytes.

The normalized exception classes retain `category`, `retryable`, `provider_status_code`, `provider_request_id`, and `redacted_message`. Defaults are authentication/non-retryable, quota/retryable, transient/retryable, and contract/non-retryable. The constructor accepts only an already-redacted message; provider payload redaction belongs to the Task 2.2 client translator.
