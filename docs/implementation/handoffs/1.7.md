## Deliverable

`KnowledgeService.resolve_index_input()` decodes the approved
`legacy-study-revision:<positive-decimal>` identity only inside Sol-1, accepts
only ready/stale/retired revisions, verifies Source Trust authority and scope,
revalidates the legacy PPTX/PDF and catalog crosswalk through existing private
read boundaries, reparses with `LegacyPptxProcessor` v1, and requires exact
normalized evidence identity. It returns deterministic opaque artifact IDs and
sorted namespaced assets without writing any repository.

The public service views list revision lifecycle and upload eligibility, and
resolve slide citations to the existing private PDF artifact identity without
returning paths or hashes. The revision route deliberately does not serialize
CP-0002's internal indexing view. The router is returned for later Sol-0
registration, serves no files, inherits the existing application authentication
and CSRF middleware, sets `Cache-Control: private, no-store`, and maps declared
missing/integrity/provenance failures to 404/409 while unexpected failures use
the application's generic 500 handling.

`mark_dependents_stale()` deliberately raises
`DependencyProvenanceUnavailable` without calling `retire_revision()` or
treating the current empty dependency result as proof that no dependencies
exist. Task 5.2 must provide durable provenance before that flow can mutate
state.
