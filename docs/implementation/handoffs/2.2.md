## Produced interfaces

- `oms_hub.providers.gemini.client.GeminiClientFactory`
- `async with GeminiClientFactory(config, sdk_factory=...).client() as client`
- `oms_hub.providers.gemini.client.translate_gemini_error(exc)`

`GeminiClientFactory` accepts a provider-local `GeminiConfig` and an optional
SDK-constructor seam. The default seam imports `google.genai` only when a
context is entered, constructs `genai.Client(api_key=..., http_options=...)`,
and yields its `.aio` facade. Each context constructs one top-level client and
awaits `.aio.aclose()` once in `finally`, including body errors. Injected fakes
receive the raw key only at the SDK boundary and the configured API version;
the `SecretStr` wrapper is never passed to the SDK.

`translate_gemini_error` preserves an existing `GeminiProviderError`, maps
authentication (401/403), quota/rate (408/429), transient service failures
(500/502/503/504 and `TimeoutError`), and SDK shape failures
(`AttributeError`/`TypeError`/`KeyError`). Status and request identity are read
only from bounded safe attributes or known headers. Messages are fixed and do
not include exception text, provider payloads, credentials, or private source
content; unknown failures use the generic redacted provider message.
