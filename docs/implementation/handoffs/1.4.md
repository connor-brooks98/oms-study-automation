## Implementation

`normalize_course_revision()` accepts the existing ordered
`ParsedDocument`/`ParsedSegment`/`SegmentKind`/`DocumentLocator` contracts and
small frozen `SlideInput` and `TranscriptSegmentInput` synthetic adapters.
Parsed segments remain in upstream order. Synthetic slides emit visible text
then a separate speaker-note unit; native text wins, with explicitly supplied
OCR used only when native text is blank. Tables stay single units, text-bearing
images map to figure locators with an unambiguous asset key, and empty text is
omitted.

Normalization only maps CRLF/CR to LF and trims outer whitespace. It does not
trim repeated headers/footers without upstream metadata, summarize, rephrase,
infer provenance, split table rows, or add facts. Every unit is
`AuthorityClass.COURSE_MATERIAL`; scope is copied from the input. Content and
IDs use exactly `sha256_text(normalized_text)` and
`evidence_id(source_revision_id, f"{kind}:{value}", content_sha256)`. The
Task 1.2 defaults remain in force for optional evidence fields.

`render_index_markdown()` emits the four required markers, a blank line, full
normalized text, deterministic double-newline unit separators, and one final
newline (or an empty string for no units).
