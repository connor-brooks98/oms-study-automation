## Implementation

`allowed_authorities()` maps the frozen `TruthMode` values exactly to course
material, course-plus-published-journal, or published-journal authorities.
`validate_scope()` checks only local identifier shape, duplicate lecture and
revision IDs, and the truth-mode enum; it does not query persistence or mutate
the frozen `RetrievalScope`.

`filter_allowed_evidence()` validates every `EvidenceUnit` scope before
authority filtering and preserves input order. Course material must match the
requested course and, for narrowed exam or lecture scopes, must carry matching
exam/lecture metadata. Populated course/exam/lecture metadata on non-course
units must match the requested populated scope; absent optional non-course
metadata is allowed. A non-empty revision allowlist is enforced, and
authority-only exclusion returns `()` without asserting insufficiency.

`assert_claim_evidence_allowed()` requires at least one reference, permits only
medical authorities enabled by the truth mode, rejects generated artifacts and
question-style references, and enforces only an explicit revision allowlist.
`EvidenceRef` lacks course/exam/lecture fields, so claim assertion does not
invent those checks. Domain exceptions are `SourceScopeError`,
`UnsupportedAuthorityError`, and `InsufficientEvidenceError`.
