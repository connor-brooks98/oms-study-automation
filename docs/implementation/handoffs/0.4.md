`AuthorityClass`: `course_material`, `published_journal`, `generated_artifact`, `question_style_reference`.
`TruthMode`: `course_only`, `course_and_literature`, `literature_only`.
`AnswerEventType`: `status`, `delta`, `citations`, `done`, `error`.

Frozen, slotted dataclasses retain this field order: `RetrievalScope(course_id, exam_id, lecture_ids, truth_mode, source_revision_ids=())`; `EvidenceRef(evidence_id, source_revision_id, authority_class, locator_kind, locator_value, excerpt, checksum)`; `RetrievalRequest(query, scope, maximum_evidence=12)`; `RetrievalResult(evidence, provider_request_id, insufficient_evidence)`; `ProviderHealth(provider, ready, detail, checked_at_iso)`; and `AnswerEvent(event_type, payload: dict[str, object])`.

`RetrievalProvider.retrieve(request: RetrievalRequest) -> RetrievalResult` and `.health() -> ProviderHealth` are async. `GroundedAnswerProvider.stream_answer(request: GroundedAnswerRequest) -> AsyncIterator[AnswerEvent]` is synchronous at invocation and returns the iterator. `GroundedAnswerRequest` is an empty public marker `Protocol`: Task 0.4 deliberately does not invent Ask fields, and later concrete request models can structurally satisfy it.

`ProviderRegistry` has instance-local retrieval and answer dictionaries only. Its explicit case-sensitive `register_retrieval`/`register_answer` reject blank and same-category duplicate names with `ValueError`; `get_retrieval`/`get_answer` reject unknown names with deterministic, sorted `KeyError` diagnostics. Categories are separate, so the same name may appear once in each.

The retrieval fake copies configured responses into an instance FIFO list, records the exact request before dequeue/exhaustion, raises `AssertionError` when empty, and returns deterministic health. `from_text` uses `course_material`, `text`, `1`, `fake-retrieval-1`, the excerpt text, and `sha256:` plus the UTF-8 SHA-256 when omitted. The answer fake copies every direct input sequence to a tuple, consumes one sequence FIFO per call, records the marker request before immediate invocation-time exhaustion, and returns an async iterator preserving configured event order. Neither fake performs provider, network, filesystem, clock, UUID, random, task, or thread work.

The authorized exporter is `python scripts/export_grounded_contract_schemas.py --output-dir <dir>`. It creates its requested directory and writes exactly six canonical UTF-8, sorted-key, two-space JSON files with one newline and no environment or path data. `knowledge-v1` is the TypeAdapter-generated retrieval bundle and `ask-v1` is the generated `AnswerEvent` schema. The four future-domain files are reserved namespaces with `"not": {}`: every wire instance is rejected until its owning task replaces the snapshot through this exporter.
