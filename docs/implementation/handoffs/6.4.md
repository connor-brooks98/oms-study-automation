## Formula and contract record

- Application evidence includes only complete `QUESTION_ANSWERED` events containing the requested objective and a valid difficulty. Non-question, incomplete, and nonmatching events contribute zero.
- Base event weight is `assistance_multiplier * difficulty_multiplier * correctness_confidence_multiplier`.
- Assistance multipliers are immutable: none `1.00`, concept hint `0.70`, source excerpt `0.55`, full explanation `0.35`, answer revealed `0.10`.
- Difficulty multipliers are immutable: 1 `0.75`, 2 `0.90`, 3 `1.00`, 4 `1.20`, 5 `1.40`.
- Correct confidence multipliers are confident `1.10`, unsure `0.85`, guessed `0.65`, not recorded `1.00`. Incorrect confidence multipliers are confident `1.15`, unsure `1.00`, guessed `1.00`, not recorded `1.00`.
- Recency is `0.5 ** (age_days / half_life_days)` with the fixed engine default half-life of 60 days. `recency_weight` rejects negative age, nonpositive half-life, NaN, infinity, and boolean numeric inputs. Future event age is clamped to zero in the engine.
- Application score is `alpha = 2 + weighted_correct`, `beta = 2 + weighted_incorrect`, then `100 * alpha / (alpha + beta)`. `evidence_weight` is weighted correct plus weighted incorrect.
- Assistance dependence is a separate recency-weighted `100 * Σ((1 - assistance_multiplier) * decay) / Σ(decay)` over scored question events. Confidence and difficulty do not enter this dimension. It is `None` without scored evidence.
- `timed_application_score` stays `None`; Task 6.3 carries no accepted timed-mode marker. `last_tested_at` is the latest scored event timestamp. Status is only `untested` (no scored evidence) or `tested` (otherwise).
- Recall retention is `None` without a snapshot. The local `ObjectiveRecallRetention.recall_retention(objective_id)` adapter returns a validated finite probability in `[0, 1]` or `None`; invalid values fail closed. This is a documented FSRS-style range judgment pending the future approved objective mapping adapter.
- `MasterySnapshot` is frozen, validates its trust-boundary values, omits volatile computation time, and serializes through sorted-key compact UTF-8 JSON. The stateless service recomputes from caller-supplied complete history; it adds no persistence or deduplication behavior.
