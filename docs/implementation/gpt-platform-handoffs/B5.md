## Integration contract

`to_review_drafts(quiz, inputs) -> tuple[QuestionDraftValue, ...]` revalidates B4
output and uses the existing draft model. It retains source-qualified segment
locators and the original question ids, puts per-choice explanations into readable
rationale, and preserves source evidence. Every answer is `GENERATED_BY_AI`,
`verification_required=True`, `verified_at=None`, including image-free quizzes.
There is no paid API accuracy fallback or automatic publication.

Constructor:

```python
GptLectureWorker(repository, client, load_inputs, model, image_service, artifact_root)
```

`load_inputs` is O's trusted `GptLectureService.load_inputs(run)` callable. The
worker requires the frozen per-run `gpt:settings` model; a changed global model
does not replace it. `StudioWorker` appends optional `gpt_worker=None` and delegates
`LECTURE_GENERATION` before notebook chat or publication work. Missing GPT worker
configuration stops through O's safe `capability_unverified` state handling.

`GptLectureWorker.run(run)` uses O's cancellation, explicit-resume and synchronous
lifecycle persistence methods. It saves `gpt:response` with the validated original
quiz, canonical hashes, manifest/model binding and private B4 evidence-directory
reference. `gpt:coverage` records every objective's question ids and source
citations. Existing `normalized` and `review:questions` artifacts hold review
drafts; recovery retains existing review edits. Selected original slide images
pass through `copy_import_candidate` and an exact source SHA check. The worker
ends at atomic `await_import_review`; it never invokes publication.

Completed response recovery verifies the private B4 final artifact and current
source bindings and makes zero client calls. Ambiguous attempts retain their
dispatch claims even with explicit resume. Failure/cancellation exits call
`stop_gpt_run` once; cancellation before the worker's first state read also
acknowledges `worker_stopping`. O's controls prevent a new resume while an old
worker is unwinding.

`PracticeReviewService` has this keyword-only constructor argument and public
attribute (default `None`):

```python
lecture_validator: Callable[
    [str, tuple[ReviewQuestion, ...], Session | None], None
] | None
```

O wires `worker.validate_review`. The existing blocker, native preview, and
`to_native_quiz_in_session` paths invoke it for lecture generation only. GPT
fails closed when it is absent; legacy import behavior is preserved. The
publication path passes its actual SQLAlchemy session. The callback calls O's
public `validate_gpt_manifest_in_session`, verifies the same-session manifest,
response, coverage and image binding rows, and rechecks original source bytes.

Edited drafts retain authoritative question/objective/source mappings. Unknown
question ids or changed source refs/objective ids block publication. Surviving
questions must still cover every objective with at least three independent
questions. Selected images must resolve to original slide assets with matching
copied bytes and question source citations. Removing the last required image or
deleting the only question for an objective blocks preview and publication.
Question edits use existing manual-review behavior and clear prior verification.
The original provider response remains separate from mutable review data.
