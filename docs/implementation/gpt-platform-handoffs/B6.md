## Boundaries and failed experiments

uses the actual production `_rasterize` method in a checked subprocess, preserving
real output metadata/assets and failing on any nonzero child exit. The combined
in-process app/PyMuPDF experiment completed assertions but crashed at interpreter
teardown (exit 139/-11, native extensions in faulthandler output). A fitz-first
whole-test process did not cure it. O authorized narrow test-only raster lifetime
isolation; exploratory converter/parser changes were removed. Both final parent
and child processes exit normally. This does not accept the problematic native
in-process runtime, and no production code masks it.

Browser test development exposed a premature image-load assertion, a CSP-blocked
string evaluation wait and an incorrect settings URL in the fixture. Corrected
checks wait for image completion, assert decoded width, and use `/settings`.
